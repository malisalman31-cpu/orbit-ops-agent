# Contributing

Thanks for helping improve Orbit Ops.

1. Fork the repository and create a focused branch.
2. Keep the application dependency-free unless a dependency materially improves reliability or accessibility.
3. Run `npm run check` and `npm run test:coverage` before opening a pull request.
4. Add tests for behavior changes, especially plan generation, validation, imports, exports, and WebMCP tools.
5. Explain the operating problem the change solves and include screenshots for interface changes.

Please do not include private operational data, customer data, credentials, or incident evidence in issues, fixtures, or pull requests.
